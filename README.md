# คณิตศาสตร์เพิ่มเติม ม.5 เทอม 2 (เว็บประกอบการเรียน)

จัดทำโดย ครูคุ้ม อชิตพล บุณรัตน์ — เพื่อการศึกษา ใช้ร่วมกับหนังสือเรียนรายวิชาเพิ่มเติม คณิตศาสตร์ ม.5 เล่ม 2 (อจท.)
หน่วยที่ 1 จำนวนเชิงซ้อน · หน่วยที่ 2 หลักการนับเบื้องต้น · หน่วยที่ 3 ความน่าจะเป็น

## นำขึ้น GitHub Pages
1. สร้าง repository ชื่อ `math-m5-plus` (Public)
2. Add file → Upload files → ลาก index.html, config.json และโฟลเดอร์ worksheets → Commit changes
3. Settings → Pages → Branch: main, /(root) → Save
4. เว็บอยู่ที่ https://ชื่อผู้ใช้.github.io/math-m5-plus/
5. อัปเดตครั้งต่อไป อัปโหลดเฉพาะ index.html (อย่าทับ config.json)

## Firebase (ใช้ร่วมกับเว็บ ม.5 พื้นฐาน)
- config.json: คัดลอก `"firebase": {...}` จากเว็บ ม.5 / ม.3 / ม.1 มาแทน `null`
- **ไม่ต้องแก้ Firestore Rules** ใช้กฎฉบับรวมเดิมได้เลย
- นักเรียนใช้ **บัญชีเดียวกับเว็บคณิตพื้นฐาน ม.5** (m5students) ถ้าสร้างบัญชีในเว็บใดเว็บหนึ่งแล้ว ล็อกอินได้ทั้งสองเว็บ
- คะแนนแบบทดสอบบันทึกใน m5tests ชื่อหน่วยขึ้นต้นด้วย "เพิ่มเติม:" แยกจากวิชาพื้นฐาน
- การเปิดเฉลยของเว็บนี้เก็บที่ settings/m5x (แยกจากวิชาพื้นฐาน)

## รหัสเฉลย (config.json หรือแดชบอร์ดครู แท็บ “เปิดเฉลย”)
"1.1" … "1.7" (จำนวนเชิงซ้อน) · "2.1", "2.2ก", "2.2ข", "2.2ค", "2.2ง", "2.3", "2.4" (หลักการนับ) · "3.1", "3.2" (ความน่าจะเป็น)
